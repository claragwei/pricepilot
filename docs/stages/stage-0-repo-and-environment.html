Milestone 0: repository and environment

A repo anyone can install, check and test the same way.

What we did

Why

  • Lockfile: exact versions, so a build today matches one in six months.
  • src/ layout: tests import the installed package, not stray local files.
  • Strict types and lint early: cheaper than retrofitting later.
  • CI: an automatic gate so a broken main branch is hard to produce.
  • Data and secrets stay out of git: large, and hard to remove from history.

How we checked it

  • uv run ruff check ., ruff format --check ., mypy, pytest: the four checks CI runs.
  • In a later session they passed on the current repo (34 tests); not re-run at the M0 commit.
  • uv sync --frozen in CI fails if pyproject.toml and uv.lock disagree.
