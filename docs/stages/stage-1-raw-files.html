Milestone 1, raw files: download, check, store

Get the source data, prove it is intact, and keep it untouched.

What we did

Why

  • Raw layer (bronze): unchanged source data; cleaning happens in later layers.
  • Checksums: same hash means same bytes, so corruption and bad re-downloads are detectable.
  • gzip: about 11x smaller, and DuckDB reads .csv.gz directly.

How we checked it

  • Archives: unzip -tq; duplicates: cmp; type: file and xxd header.
  • That header check showed 13 UPC downloads were SAS binaries, not CSV; they were re-downloaded and checked.
  • Round trip: decompress each .gz, recompute SHA-256, compare: 58 of 58 matched.
