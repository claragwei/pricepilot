Slice 1a: Postgres container and dbt skeleton

A local, reproducible database and an empty dbt project that connects to it.

What we did

Why

  • Docker: same database for you, CI and anyone else.
  • Healthcheck: says the database accepts connections, not just that the container started.
  • Named volume: data survives recreating the container.
  • 127.0.0.1 binding: keeps the database off the network.
  • env_var() in dbt: no secrets in files.

How we checked it

  • docker compose up -d: container reported healthy.
  • uv run dbt debug --project-dir dbt --profiles-dir dbt ended with "Connection test: OK".
