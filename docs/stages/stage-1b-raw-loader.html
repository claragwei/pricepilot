Slice 1b: raw loader into Postgres

Copy every source file into Postgres, and refuse any file that does not verify.

What we did

Why

  • COPY: the fast bulk-load path; streaming keeps a 458 MB file out of memory.
  • Header-name mapping: movement files come in 3 column orders; loading by position would swap columns silently.
  • Hash and row count in one transaction: a bad file never becomes a table.
  • Hex columns dropped: they duplicate PRICE and PROFIT and would cost about 5 GB; originals remain.

How we checked it

  • Row counts vs gzip -dc | wc -l minus header, run separately from the loader: all 56 match.
  • A wtti and a wgro source row match their table rows value for value.
  • 6 unit tests and 2 integration tests against the real container (they skip if Postgres is down).
